## What this FIXME asks for
Live restore is a feature that enables online migration from a backup source to a destination directory while the database remains open. The file-system layer (`WTI_LIVE_RESTORE_FS`) is currently implemented only for POSIX platforms (`#if defined(__APPLE__) || defined(__linux__)`). On Windows (detected via `_MSC_VER`) the connection API returns `EINVAL` immediately, preventing any use of live restore. The nested-directory creation code (for MongoDB's directory-per-db layout) also uses POSIX-only `strstr`/path-separator logic. The FIXME asks for a Windows-compatible implementation of the live-restore filesystem layer and the directory-creation helper.

## Importance: MEDIUM
**Reasoning**: Live restore is a production feature for MongoDB. Windows is a supported platform for WiredTiger. The current code returns a clean error rather than crashing, so there is no data-corruption or crash risk, but the feature is completely unavailable on Windows. Any MongoDB deployment on Windows that relies on live restore for migration is blocked.
