## What this FIXME asks for
When draining ingest tables during layered table management, the code currently processes all ingest tables including empty ones. The FIXME requests an optimization to skip empty ingest tables before queuing them for drain work, avoiding unnecessary work when a table has no data to drain. This is a known low-hanging performance improvement described in the Jira ticket as the primary concrete item of work.

## Importance: LOW
**Reasoning**: This is a performance optimization only — there is no correctness risk. Empty ingest tables are processed unnecessarily, wasting CPU cycles during drain operations, but the drain still completes correctly. The ticket is P4/Minor and sits in backlog. A diagnostic post-condition check for empty ingest tables was added in WT-16962 (2026-03-19), which partially mitigates the issue by catching problems rather than preventing the inefficiency.
