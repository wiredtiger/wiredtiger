## What this FIXME asks for
`__wti_debug_crash_if_flag_set` is a hand-rolled crash injection mechanism used during schema operations (create/drop) to simulate crashes mid-operation for testing metadata consistency. It checks a debug flag, logs a warning, sleeps 2 seconds, then calls `__wt_abort`. The FIXME requests that once a proper failpoint framework is available this ad-hoc function be replaced with it, providing cleaner, more controllable crash injection with better test integration.

## Importance: LOW
**Reasoning**: The current implementation is functionally adequate for its purpose — simulating crashes at specific schema operation points. The FIXME is about code quality and maintainability: a proper failpoint framework would offer more flexibility and consistency. There is no correctness risk from leaving the current implementation in place.

## Test Coverage: PARTIAL
**Relevant tests**: none found in test/ specifically referencing WT-12021; the crash points are exercised indirectly by schema operation tests that set the debug flags (schema_create, schema_drop call sites in src/schema/)
**Gap**: No dedicated test exercises all four `__wti_debug_crash_if_flag_set` call sites systematically, and the 2-second sleep before abort makes the crash injection coarse.
