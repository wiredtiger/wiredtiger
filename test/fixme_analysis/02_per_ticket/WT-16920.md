## What this FIXME asks for
The disagg test hook maintains `testcase.layered_uris` and `testcase.non_layered_uris` as flat sets on the test case object, shared across all connections in a test. When a test opens multiple connections to different home directories, the same URI in different homes would be confused, because the sets do not distinguish which home directory a URI belongs to. The FIXME defers implementing per-home-directory URI tracking, which would require associating each URI with its home directory string.

## Importance: LOW
**Reasoning**: This is purely a test infrastructure limitation. No existing disagg tests currently exercise multiple connections on multiple home directories, so there is no known failing test scenario. The risk is that future tests using that pattern could incorrectly classify a URI as layered or non-layered, producing misleading test behavior rather than a production data correctness issue.
