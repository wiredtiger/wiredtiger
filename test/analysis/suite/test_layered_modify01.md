# test_layered_modify01 — cursor.modify() correctness across a checkpoint on a layered table

**File:** `test/suite/test_layered_modify01.py`
**Storage mode:** Disagg/Layered (disagg_only, palite page log)
**Components under test:** `cursor.modify()` on a follower after picking up a leader checkpoint, modify validity across stable/ingest boundary, value format coverage (string and raw bytes)

## Test Cases

### `test_layered_modify01.test_layered_modify01`
- **What it tests:** Leader creates a layered table (`key_format=i,value_format=S|u`) and writes 1000 keys (0–999). Each value is generated by `create_value()` using a fixed-seed RNG (seed=42) with a random size (1000–10000 bytes), a random repeat pattern, and a random number of modifications (1–10) and max-diff (64–size/10). After writing all 1000 keys, the leader checkpoints. The connection is then reopened as a follower (`disaggregated=(role="follower")`) using `disagg_get_complete_checkpoint_meta()`. For each of the 1000 keys (in order), `create_mods()` generates a new set of `WT_MODIFY` descriptors that transform the original value to a new expected value. `cursor.modify(mods)` is called inside a transaction committed at `commit_timestamp=k+1`. After commit, `cursor[k]` must equal the expected new value. Verifies that `cursor.modify()` produces the correct result when the base value came from a stable checkpoint (not from an in-memory ingest write).
- **Components:** `src/cursor/cur_layered.c`, `src/cursor/cur_modify.c`, modify on stable-sourced base value, value format correctness (string vs. raw bytes)
- **Notes:** Parametrized by value format: `valuefmt='S'` (UTF-8 string) and `valuefmt='u'` (raw bytes item). The `modify_utils` helpers `create_value` and `create_mods` use a seeded random source for reproducibility. The test exercises the case where the pre-modify value must be read from the stable btree (the leader checkpoint) rather than from an ingest-local update chain, ensuring the modify path correctly retrieves and applies deltas on top of checkpointed values.
