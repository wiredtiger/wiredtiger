# test_util01 — wt dump CLI and dump cursor API for binary key/value data

**File:** `test/suite/test_util01.py`
**Storage mode:** General
**Components under test:** `wt dump` CLI, dump cursor API, byte escaping, timestamp-based dump

## Test Cases

### `test_util01.test_dump_process`
- **What it tests:** Runs `wt dump` on a table with binary (`u` format) keys and values containing all byte values 1–255; compares stdout to expected dump format with non-printable bytes escaped as `\hh`.
- **Components:** `util_dump.c`, `cursor.c`
- **Notes:** Uses `suite_subprocess`. Expected output generated by `dumpstr()` which escapes bytes < 0x20 or > 0x7e except `\` (as `\\`).

### `test_util01.test_dump_process_hex`
- **What it tests:** Runs `wt dump -x` on the same table; compares stdout to hex-format dump where all bytes are output as two hex digits.
- **Components:** `util_dump.c`, `cursor.c`
- **Notes:** Hex format omits escaping — each byte becomes exactly 2 hex chars.

### `test_util01.test_dump_api`
- **What it tests:** Opens a dump cursor (`dump=print`) via the API; reads key/value pairs and compares to expected print-format output (same escaping as `test_dump_process`).
- **Components:** `cursor.c`, `util_dump.c`
- **Notes:** Exercises the `dump=print` cursor config; output format identical to CLI `wt dump`.

### `test_util01.test_dump_api_hex`
- **What it tests:** Opens a dump cursor (`dump=hex`) via the API; reads key/value pairs and compares to expected hex-format output.
- **Components:** `cursor.c`, `util_dump.c`
- **Notes:** Exercises the `dump=hex` cursor config; output format identical to CLI `wt dump -x`.

### `test_util01.test_dump_process_timestamp_old`
- **What it tests:** Inserts 5 records at commit_timestamp=5; runs `wt dump -t 5` (read_ts=5); verifies all 5 records are visible in the dump.
- **Components:** `util_dump.c`, `txn_timestamp.c`
- **Notes:** read_ts == commit_ts so data is visible.

### `test_util01.test_dump_process_timestamp_none`
- **What it tests:** Inserts 5 records at commit_timestamp=5; runs `wt dump -t 3` (read_ts=3); verifies the dump output contains no records (data not yet committed at read_ts=3).
- **Components:** `util_dump.c`, `txn_timestamp.c`
- **Notes:** read_ts < commit_ts so no records are visible; dump still produces header/footer but no data lines.

### `test_util01.test_dump_process_timestamp_new`
- **What it tests:** Inserts 5 records at commit_timestamp=5; runs `wt dump -t 7` (read_ts=7); verifies all 5 records are visible.
- **Components:** `util_dump.c`, `txn_timestamp.c`
- **Notes:** read_ts > commit_ts so data is visible.
