## Fixes to `dist/s_copyright`

### Template indentation bug (tab vs space)
Templates c1 and c5 had `*    All rights reserved.` (4 spaces).
Virtually all C/H files in the codebase use `*\tAll rights reserved.` (tab).
The template had never matched the actual files. Fixed with:
```bash
perl -i -pe 's/^ \*    All rights reserved\./ *\tAll rights reserved./'
```

### `.venv` exclusion added to `find` pipeline
`tools/wt-mcp/.venv/` is a committed Python virtual environment with 1196 third-party
packages. Added `-e '/\/\.venv\//d'` to the sed exclusion pipeline.
This alone reduced failures from ~1700 to 80.

### Encoding-comment offset check added
`bench/perf_run_py/*.py` files legitimately start with `#!/usr/bin/python\n# -*- coding: utf-8 -*-\n\n`,
which pushes the copyright block to lines 5–8 rather than lines 3–6.
Added a new variant to the `check()` function:
```bash
{ sed -e 5,7p -e 8q -e d $1 | diff -q - $c4 > /dev/null; } && return 0
```
